# Week 2 - Arrays & Functions

This repository contains the Week 2 assignments and mini project covering:

- 1D & 2D Arrays
- User-defined Functions
- Passing Arrays to Functions

## Assignments

1. Find largest element in an array
2. Count positive and negative numbers
3. Function to find factorial
4. Add two matrices

## Mini Project

**Student Average Calculator with Functions**

The mini project accepts marks for multiple subjects, calculates the total and average using functions, and displays the result.

## How to Run

Compile any `.c` file using a C compiler:

```bash
gcc filename.c -o program
./program
```

On Windows:

```bash
gcc filename.c -o program.exe
program.exe
```
